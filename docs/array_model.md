# Array model

The browser supports an east-west pair, an L layout and a four point Y layout. These are synthetic educational geometries.

For every pair, the code projects the local east, north and up baseline coordinates into u, v and w as the source hour angle changes. All pair tracks contribute to the coverage and response panels.

The response panel is a naturally weighted Fourier response from the sampled tracks. It is not a reconstructed or calibrated sky image.

The selected longest projected pair supplies the single fringe and binary-visibility readouts.
