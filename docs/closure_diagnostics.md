# EHT M87 closure and uv sampling checks

This is an **independent, descriptive analysis** of the repository-retained 2017 EHT network-calibrated Stokes-I visibility CSVs; the browser imaging pipeline is unchanged.

1. **Closure phases:** simultaneous triangle products `V_ab V_bc V_ca` with baseline orientation correctly conjugated. Station-based antenna phase errors cancel in the ideal model. A first-order thermal phase uncertainty uses `sqrt(sum((sigma/|V|)^2))` radians. A minimum baseline SNR of 3 is required. This is not a calibrated closure-phase science product; low-SNR bias, correlated noise and calibration systematics are omitted.
2. **Log closure amplitudes:** four-station `ln(|V_ab V_cd / V_ac V_bd|)` cancels multiplicative station gains. The propagated thermal uncertainty uses the quadrature sum of four fractional errors. One deterministic ratio is used per sorted quadrangle; low-SNR amplitude bias is not corrected.
3. **Hermitian uv sampling:** eigenvalues of the symmetric second-moment matrix describe sampling anisotropy and the inverse-frequency angular-scale proxies `1/(2π sqrt(eigenvalue))`. These are **not beam FWHM or an image-resolution measurement**. Leave-one-UTC-hour-out checks expose dependence on observing-hour coverage.

Run `python -m unittest discover -s tests -v` and `python tools/run_closure_diagnostics.py`. The runner reads all eight repository-retained CSV files, verifies row counts against the retained metadata, and prints a per-file JSON summary. **Important provenance limitation:** the committed `095_hi` CSV is 522,380 bytes whereas its acquisition metadata records 528,840 bytes. The cached GitHub CSVs therefore cannot be certified byte-identical to the acquisition manifest without further investigation; the runner deliberately does not claim a SHA-256 integrity validation. The original `tools/validate_observations.py` integrity check is not used by this diagnostic workflow until the discrepancy is resolved. Missing triangles/quadrangles are not fabricated; samples are grouped at the CSV's exact released UTC timestamp and the best fractional-error duplicate per baseline is selected. Read `data/observations/eht_m87_2017_metadata.json` for release provenance. No new imaging, detection, ring-diameter fit or cosmological inference is claimed.
